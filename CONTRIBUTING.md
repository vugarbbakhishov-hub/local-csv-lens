# Contributing

Thanks for helping improve Local CSV Lens.

## Before opening an issue

- Remove private or sensitive data from CSV examples.
- Describe the delimiter, line endings and quoting pattern that caused the problem.
- Include the smallest CSV sample that reproduces the behavior.

## Pull requests

1. Keep the change focused on one problem.
2. Add or update a parser test when behavior changes.
3. Run `npm test`, `npm run lint` and `npm run build`.
4. Explain the user-visible result and any limits in the pull request description.

Please do not submit real personal, financial, health or customer data in issues or fixtures.
